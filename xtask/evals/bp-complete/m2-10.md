## Problem

22 caps every non-test source file at 500 lines, and nothing enforces it. Each pull request checks it by hand with `wc -l`; `index.rs` reached 462 non-test lines.

## Shape

`cargo xtask lines` counts each `.rs` file's lines before its first `#[cfg(test)]`, over `crates/` and `xtask/`. A file over 500 prints its path and count and exits 2. `just ci` and CI run it beside `cargo xtask deps`.

## Check

~~~check shell {name=file-cap expect=0}
cargo xtask lines
T=$(mktemp -d); cp -R .cargo crates xtask Cargo.toml Cargo.lock rust-toolchain.toml $T/; printf 'fn a() {}\n%.0s' $(seq 501) > $T/crates/bp-vault/src/zz.rs
rc=0; (cd $T && cargo xtask lines) || rc=$?; test $rc -eq 2
~~~
